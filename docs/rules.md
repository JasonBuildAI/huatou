# 判据表（rules）

这份表是 [`design.md`](design.md) 的落点清单：每条判据一行，写清它**回答什么问题**、
**落在哪个文件**、**证据是哪一天量到的**、以及**哪些地方刻意不放宽**。

## 读法（三条，先读再往下）

- **证据是判据的一部分。** 真机证据解释了「为什么放宽到这里就停」；没有证据的放宽
  不许进代码（`design.md` §8）。所以每一行都带日期，日期是它被量到的那一天。
- **不对称的账要写下来。** 判据两边的代价不一样时（误认 vs 漏掉），写清朝哪边偏、
  为什么偏 —— 否则下一个人会按对称的直觉把它改回去。
- **数字分三档**：**实测**（真机跑出来的比率）／**产品口径**（用户直接给的期望）／
  **拍的**（没有测量，只是起点）。每一档都照实标，别让下一个实现者以为它们一样硬。

## §1 `asks_the_user` —— 她有没有在问他

判据**不是**「带问号」。真机 2026-09-23 那串自问自答里，她那两句问号都没有，
紧接着的定时主动就把话续上了，用户读到的就是「她替我答了」。所以这一档认六种形状，
从上往下判，任一命中即为真：

| # | 形状 | 判据 | 证据与日期 |
|---|---|---|---|
| 1 | 问号收口 | 去掉尾部引号 / 括号后以 `?` `？` 收口 | 常规形状 |
| 2 | 疑问词 | `什么 / 怎么 / 咋 / 哪[儿里个天] / 几点 / 多少 / 谁 / 几[个天] / 是不是 / 有没有 / 要不要 / 好不[好嘛] / 行不行 / 知不知道 / 记不记得 / 想不想 /（逗号后的）还是`，**并且**先排除否定前缀（没什么 / 不怎么 / 哪有 / 别无） | 真机 2026-09-23 通话「最近怎么了呀」；同日判定式评测再补「谁」「几天」两格 |
| 3 | 句中「吗」 | **不挑位置** | 真机 2026-09-23 23:04「还没哦，画到一半。你呢，今天不是坐了很久地铁吗，现在到哪了」—— 收口是「到哪了」，只认收口的老判据认不出 |
| 4 | A 不 A | 收口在一个裸「没」上，且前面不是「还不也都没」 | 真机三句：「你到宿舍了没」「那起来之后吃了东西没」「你今天坐了那么久地铁到家了没」 |
| 5 | 语气词收口（硬档） | `吗` `么` | 常规 |
| 6 | 语气词收口（软档） | `吧呢呀啊呗嘛` 收口，**且句中出现第二人称**（你 / 您 / 咱） | 真机「你不是说这几天要调养嘛」 |

第 5 条的「吗」实际会被第 3 条先接住；它留在表里，是因为**收口**这一档还管着「么」，
而「么」不跟着放宽到句中（理由见 §1.2）。第 6 条要求第二人称，是为了把
「那就快去睡吧」这种叮嘱挡在外面。

**这一档认的是形状，不是语义**：招呼类（「你好呀」）与道谢类（「谢谢你呀」）
也会被认成问句。这笔账在 §1.3。
